A collection of Python programs developed while studying A-level Computer Science. These projects demonstrate object-oriented programming (OOP), inheritance, method overriding, data handling, and basic problem-solving.

Projects

1. Employee Payroll System — Q28.py

Demonstrates an employee payroll system using classes and inheritance.

Concepts covered:

Classes and objects

Constructors (__init__)

Encapsulation and getter methods

Inheritance using Employee and Manager

Method overriding

Calculating weekly and total pay

2. Character Movement System — Q29.py

A character movement program in which characters can move in different directions within defined coordinate boundaries. A bike character inherits from the base character class and moves at a different speed.

Concepts covered:

Classes and objects

Inheritance

Method overriding

Getters and setters

Input validation

Conditional statements

3. Character Intelligence System — Q30.py

A character-based program that models character attributes and intelligence improvements. It includes a MagicCharacter subclass with its own version of the Learn() method.

Concepts covered:

Classes and objects

Inheritance using Character and MagicCharacter

Constructors and super()

Method overriding

Date handling with Python's datetime module
